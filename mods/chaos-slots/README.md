# Chaos Slots

![logo](mod/about/preview.png)

## Русский

Дополнительные ячейки эссенций от Искажённого Хаоса можно ставить туда, где они нужнее. Вложите все четыре в одно воспоминание или распределите их между воспоминаниями. У каждого игрока свой лимит в четыре дополнительные ячейки.

## English

Put the extra Essence slots you earn from Corrupted Chaos on the Memories you use most. You can put all four on one Memory or spread them across Memories. Each player can earn up to four extra slots in total.
