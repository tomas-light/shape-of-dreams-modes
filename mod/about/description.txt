Distribute up to four extra Essence slots earned from Corrupted Chaos among your Q, W, E and R Memories. In co-op, each player has their own four-slot limit. Bonus slots form an arc above each Memory. Drag the petal above a bonus slot onto a highlighted Memory to move the slot and equipped Essence. Each player's layout follows the host's run save.

Solo and co-op play on the Steam edition. Enable the same version of Chaos Slots on the host and each guest. Use the same player profiles when continuing a co-op run. Open the Memory editor (hold Left Ctrl by default) to drag slots. Use Chaos Slots on its own if you have other mods that change Essence slot counts.
