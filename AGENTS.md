# Shape of Dreams Mods

## Организация модов

- Для отдельного мода создавай папку `mods/<имя-мода>/` по образцу Chaos Slots и Constellation Viewer. Исходники размещай в `src/`, тесты в `tests/`, скрипты упаковки в `scripts/`, материалы демонстрации в `images/`.
- Добавляй мод в русский и английский списки корневого `README.md`. В README самого мода кратко объясняй его назначение на русском и английском. Раздел «Демонстрация / Gameplay» оформляй по образцу Chaos Slots. Встраивай скриншоты и GIF относительными ссылками на `images/`. Кадрируй демонстрацию так, чтобы были видны нужное действие и читаемый текст интерфейса.
- Веди одну общую инструкцию по сборке и установке в [mods/build.md](mods/build.md). Добавляй туда вызов `scripts/Pack-Mod.cmd` для нового мода и ссылайся на соответствующий раздел из его README. Скрипты собирают папки модов и ZIP-архивы с версиями в `artifacts/`. Версию пакета бери из `mod/about/metadata.json`.

## Steam Workshop

- Храни описание в `mod/about/description.txt`, обложку в `mod/about/preview.png`, иконку списка модов в `mod/about/icon.png`. Включай эти файлы в пакет вместе с манифестом и DLL.
- Оформляй описание по образцу `mods/chaos-slots/mod/about/description.txt`. Используй BBCode и три раздела — «Русский», «English» и «Демонстрация / Gameplay». Для GIF в тегах `[img]` используй публичные прямые ссылки на файлы из репозитория. Проверяй доступность ссылок перед публикацией.

## Код-ревью

- Когда пользователь просит независимое ревью без передачи контекста, запускай ревьювера с `fork_turns: "none"`. Передай требования к изменению, исправь подтверждённые проблемы и запроси повторное ревью.
- Выводи замечания обычным Markdown-списком в финальном ответе. Для каждого указывай приоритет, путь и строку, проблему и предлагаемое исправление. Не используй `::code-comment` и inline-карточки.
